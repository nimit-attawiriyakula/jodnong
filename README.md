# เว็บไซต์ จดน้อง (GitHub Pages)

ไฟล์ทั้งหมดในโฟลเดอร์นี้คือเว็บไซต์ ไม่ต้อง build ไม่มีค่าใช้จ่าย

| ไฟล์ | คืออะไร |
|---|---|
| `config.js` | **แก้ไฟล์นี้ไฟล์เดียว**: LINE ID, อีเมล, ผู้ควบคุมข้อมูล, ระยะเวลาเก็บข้อมูล |
| `index.html` | หน้าแรก + วิธีใช้งาน |
| `privacy.html` | นโยบายความเป็นส่วนตัว (PDPA) |
| `style.css`, `main.js`, `assets/` | หน้าตา, ปุ่มเปลี่ยนภาษา/QR/คัดลอกตัวอย่าง, รูป |

เปิดหน้าเว็บด้วย `?lang=en` ท้ายลิงก์ = เปิดเป็นภาษาอังกฤษทันที
